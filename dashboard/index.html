{ 02 // stack }

The stack

Every tool below is wired and has run for real. Nothing here is aspirational.

  1. Sources Application tracker (Postgres), HubSpot CRM, ATS boards
  2. Ingest Fivetran connectors
  3. Warehouse BigQuery, raw and analytics datasets
  4. Transform dbt Core, staging models into funnel and scoring marts
  5. Activate Hightouch reverse ETL into HubSpot and a daily targets sheet
  6. Orchestrate Airflow on Astro, a single scheduled DAG
  7. Control plane A Claude agent reads the marts and drafts outreach for me to approve
